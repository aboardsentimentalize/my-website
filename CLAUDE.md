# Project Notes

## Deployment

This site deploys to GitHub Pages from the `build/` directory (not the repo root). Any changes to HTML files, JSON files, or images must also be copied into `build/` or they won't appear on the live site at lilylourigan.com.

## Workflow

The user wants requested changes to go live right away — no review step, no pull requests. Commit and push directly so the change reaches `main` (and thus the live site) without waiting for a PR or approval.
